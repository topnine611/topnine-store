# Topnine AI Marketing

وكيل التسويق والإعلانات وتحسين محركات البحث لمتجر Topnine Sport.

## الحالة الحالية
هذه مرحلة التأسيس: خدمة FastAPI أولية، PostgreSQL عبر Docker Compose، وفحص صحة الخدمة. لا توجد اتصالات فعلية مع سلة أو Google أو OpenAI بعد.

## المتطلبات
- Ubuntu 24.04 LTS على VPS
- Docker Engine و Docker Compose plugin
- Git

## التشغيل محلياً أو على VPS
1. انسخ `.env.example` إلى `.env`:
   ```bash
   cp .env.example .env
   ```
2. عدّل كلمات المرور والقيم السرية داخل `.env`. لا ترفع الملف إلى GitHub.
3. شغّل:
   ```bash
   docker compose up -d --build
   ```
4. افحص الخدمة:
   ```bash
   curl http://localhost:8000/health
   ```

## المكونات
- `app/main.py`: تطبيق FastAPI وفحص الصحة.
- `docker-compose.yml`: خدمة التطبيق وقاعدة البيانات.
- `.env.example`: أسماء متغيرات البيئة فقط، دون أسرار.

## ضوابط الأمان
- لا تضع مفاتيح API أو كلمات المرور في GitHub.
- ابدأ بوضع القراءة والتحليل فقط.
- أي نشر إعلان أو تغيير ميزانية أو تعديل منتج يحتاج موافقة صريحة.
- لا يتم تخزين بيانات بطاقات الدفع أو كلمات مرور المتجر.

## الخطوات التالية
1. تأمين VPS وجدار الحماية وHTTPS.
2. ضبط أسرار الإنتاج وقاعدة البيانات.
3. إضافة مصادقة للوحة التحكم.
4. إضافة OpenAI Agents SDK وأدوات الوكلاء.
5. ربط سلة وGoogle بعد إعداد صلاحيات OAuth وواجهات API.
